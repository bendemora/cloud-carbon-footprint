grid-intensity: add the resolver (source order, licence gating, store reads with fetches of missing periods only, time-weighting, negative caching), an in-memory store and the `resolveEmissionsFactors` adapter. A source counts as fine enough when its data is no coarser than the usage period (daily for a week, monthly for a quarter). Stored points are used regardless of the source's lookback window or recent failures, which limit fetches only. A source covering only part of a period is a fallback: a later source that covers the whole period wins, except the static source over partial live data. A day running past the end of a source's data is served from its finest data up to that point, marked estimated. Points that are not whole UTC periods of the requested granularity and zone are dropped. Warnings repeat at most once per source, zone and kind per capability TTL, and `session`-retention points are kept in memory until the first resolve call after the TTL. A resolved 0 gCO2e/kWh gives 0 emissions rather than NaN. common: add the `GRID_INTENSITY` configuration block (`GRID_INTENSITY_SOURCES`, `GRID_INTENSITY_LICENCE_ACKNOWLEDGEMENTS`, `GRID_INTENSITY_CAPABILITY_TTL_HOURS`).
