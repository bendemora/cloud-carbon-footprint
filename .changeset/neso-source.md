grid-intensity: add the `neso` grid intensity source (`NesoSource`), the first source of live data: hourly carbon intensity for Great Britain from the national series of the NESO Carbon Intensity API. With `GRID_INTENSITY_SOURCES=neso,static`, estimates for AWS `eu-west-2`, Azure `uksouth` and `ukwest` and GCP `europe-west2` use the mean of NESO's outturn ("actual") values over each usage period in place of the static annual factor, at quality tier B for daily usage. Every other region is unchanged, and so is everything with the default configuration. The values are consumption-based with direct CO2 factors (gCO2/kWh, not CO2e), and they are the national figure, not one for the place a data centre is in. For GCP `europe-west2` they are used whether or not `GCP_USE_CARBON_FREE_ENERGY_PERCENTAGE` is set. An hour is offered two hours after it ends, so that values NESO may still change are not stored. A period with hours missing is marked estimated (tier C) and NESO's forecast is never used. When NESO fails, or answers in a form the source does not know, one warning is logged and a usage period is served from the hours already stored for it, or from the static factors when there are none. A half hour whose actual is 0 or above 1,500 counts as missing. When a request after the first of a long range fails, the hours of the requests before it are kept. Requests to NESO go out one at a time and at least a second apart, because NESO limits the rate of requests and publishes no figure. The licence is CC BY 4.0 and the doctor prints the attribution. The API is public and needs no registration or credentials. Also exported: `NESO_SOURCE_ID`, `NESO_ZONES`, `NESO_HOLD_BACK_HOURS`, `NESO_MIN_REQUEST_INTERVAL_MS`, the `NesoSourceOptions` type, `PartialFetchError` and `partialPointsOf` (for a source that read part of a range before it failed) and `MAX_G_CO2E_PER_KWH`. The source is tested against responses recorded from the API on 2026-11-10 and has not yet been run against the live API. api, cli, create-app: the `.env` templates name `neso,static` as the setting for Great Britain. api: the description of `GET /api/grid-intensity/capabilities` says that each source is probed once per capability TTL, which for `neso` is one request.
